# 介紹

VMware Workstation 是由 VMware 開發的桌面虛擬機軟體，
博通（Broadcom）於 2023 年 11 月收購 VMware 後，
於 2024年5月14日，[宣布](https://blogs.vmware.com/workstation/2024/05/vmware-workstation-pro-now-available-free-for-personal-use.html)將以下虛擬化軟體供免費使用。
商業使用現在也是[免費](https://blogs.vmware.com/cloud-foundation/2024/11/11/vmware-fusion-and-workstation-are-now-free-for-all-users/)。

- VMware Workstation Pro : 支援 Windows 與 Linux
- VMware Fusion Pro : 支援 macOS

# 下載 VMware

1. 註冊登入Broadcom帳號

https://profile.broadcom.com/web/registration

2. 下載 VMware

- [VMware Workstation Pro](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Workstation%20Pro&freeDownloads=true)

- [VMware Fusion](https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Fusion&freeDownloads=true)

1. 點擊下載連結後先選擇作業系統，再選擇 VMware 版本
   <img src="/images/tools/VMware/vmware1.webp" alt="" title="選擇版本" style="width: 80%;">

2. 同意條款後，點擊下載
   <img src="/images/tools/VMware/vmware2.webp" alt="" title="點擊下載icon" style="width: 80%;">

3. 填寫基本資料，點選submit送出
   <img src="/images/tools/VMware/vmware3.webp" alt="" title="填寫基本資料" style="width: 80%;">

4. 回到步驟2的頁面，點擊下載

# VMware Tools

https://knowledge.broadcom.com/external/article/315382/overview-of-vmware-tools.html
安裝後，虛擬機可以有更流暢的操作體驗，包括：

1. 滑鼠：提高操作系統中的滑鼠控制。
2. 時間同步：能夠將操作系統的時間與主機同步。
3. 改善的用戶體驗：剪貼板共享、拖拽文件、等功能。
4. 快照功能：能在虛擬機快照時保持操作系統的一致性。
