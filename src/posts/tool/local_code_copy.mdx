檔案會在瀏覽器中讀取。本工具不會主動上傳檔案內容。

雖然現在的 AI agent 或是 cli 工具很強大，但是在使用網頁版 AI 聊天頁面協助程式碼開發時，這個工具可以方便地提供程式碼或文字上下文給 AI 作為參考。

## 略過清單設定

- 點擊右上角的 **設定** 可以管理略過清單，會被標記為 **已略過**，避免瀏覽器載入大型目錄（如 `node_modules` 或 `.git`）時崩潰。
- 可以新增或刪除這些略過規則，設定會儲存於瀏覽器 (LocalStorage) 中。若變更了設定，需重新「選擇資料夾」才會套用新規則。

## 輸出限制

1. 每個檔案內容前後會自動加上路徑跟檔名的標記，`----- BEGIN FILE: src/index.ts -----`。
2. 依檔案內容判斷是否為可複製的文字資料，非純文字內容會被略過，並顯示略過提示。
3. 單一檔案大小超過 700KB 將被略過；若總複製內容超過 5,000,000 個字元，輸出將會在達到上限時截斷，避免剪貼簿或瀏覽器卡住。
