# Oh My Posh

https://github.com/JanDeDobbeleer/oh-my-posh

使用 Winget 安裝

```powershell
winget install JanDeDobbeleer.OhMyPosh -s winget
```

## 安裝 Nerd Font 字體

**Nerd Font** 字體(NF 字體)，可以顯示 Oh My Posh 的圖示 (Icons)和特殊符號 (Glyphs)。

我使用的是 [maple mono NF CN](https://github.com/subframe7536/maple-font)

* 設定 powershell 字體：

設定檔 > powershell 或是你用的 > 外觀 > 字體

## 修改 PowerShell 配置文件

1. 確認配置文件路徑：

```powershell
echo $PROFILE
```

創建配置文件（如果不存在）：

```powershell
if (!(Test-Path -Path $PROFILE)) {
      New-Item -Type File -Path $PROFILE -Force
}
```

2. 編輯配置文件：

```powershell
code $PROFILE
```

添加以下內容：

```powershell
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\jandedobbeleer.omp.json" | Invoke-Expression
```

- `$env:POSH_THEMES_PATH` 是預設的主題存放路徑。
- `jandedobbeleer.omp.json` 是預設主題，你可以根據喜好更換。

預覽主題: https://ohmyposh.dev/docs/themes

更改主題: 編輯 `$PROFILE` 文件，將 `--config` 的主題路徑修改為你選擇的主題，重啟後生效。

自訂主題:  https://ohmyposh.dev/docs/installation/customize

## 依系統深淺色自動切換主題

兩份主題放在 `$PROFILE` 同一層的 `Themes` 資料夾，把 `$PROFILE` 裡原本的 `oh-my-posh init` 換成：

```powershell
$PoshThemeDir = "$(Split-Path $PROFILE)\Themes"

function Get-PoshMode {
    if ($env:POSH_MODE -in 'light', 'dark') { return $env:POSH_MODE }
    try {
        $light = Get-ItemPropertyValue 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize' -Name AppsUseLightTheme -ErrorAction Stop
    } catch { $light = 0 }
    if ($light -eq 1) { 'light' } else { 'dark' }
}

function Set-PoshMode {
    param([ValidateSet('light', 'dark', 'auto')][string]$Mode = 'auto')
    $env:POSH_MODE = if ($Mode -eq 'auto') { $null } else { $Mode }
    $config = if ((Get-PoshMode) -eq 'light') { "$PoshThemeDir\custom-light.omp.json" } else { "$PoshThemeDir\custom.omp.json" }
    oh-my-posh init pwsh --config $config | Invoke-Expression
}

Set-PoshMode ($env:POSH_MODE ?? 'auto')
```

- 開新分頁時，讀 Windows「應用程式模式」的深淺色設定（registry 的 `AppsUseLightTheme`）決定用哪份主題
- 在目前分頁手動切換：`Set-PoshMode light`、`Set-PoshMode dark`，`Set-PoshMode auto` 回到跟隨系統
- 想固定用某一份，設環境變數 `POSH_MODE=light` 或 `POSH_MODE=dark`

## Tabby 終端機設定

我現在用 [Tabby](https://tabby.sh/) 當終端機。Tabby 沒有 Oh My Posh 專用設定，主題都在 PowerShell profile 裡處理，Tabby 這邊只要調這幾項（設定存在 `%APPDATA%\tabby\config.yaml`）：

- 字體：Settings > Appearance > Font，選 Nerd Font（我用 `Maple Mono NF CN`）
- 配色跟隨系統：`appearance.colorSchemeMode: auto`，深色、淺色各設一組配色，跟上面 profile 的自動切換剛好對上
- 最低對比度調低：`terminal.minimumContrastRatio` 從 6 改成 3 ，比較適合淺色主題
